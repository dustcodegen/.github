# Dust Codegen

**Rust-powered, batteries-included code generation for full-stack Dart and
Flutter.**

Generate data classes, JSON, validation, HTTP clients, routing, state
management, localization, and SQL—without `build_runner`. Dust also ships a
Dart HTTP server runtime.

[Website](https://dustcodegen.github.io/) ·
[Repository](https://github.com/dustcodegen/dust) ·
[Documentation](https://github.com/dustcodegen/dust/tree/main/docs/usage) ·
[Discussions](https://github.com/dustcodegen/dust/discussions)

## Packages

| Package | Purpose |
| --- | --- |
| [`dust_dart`](https://pub.dev/packages/dust_dart) | Data classes, JSON, validation, HTTP clients, and database contracts |
| [`dust_flutter`](https://pub.dev/packages/dust_flutter) | Routing, state management, and localization |
| [`dust_db_sqlite3`](https://pub.dev/packages/dust_db_sqlite3) | Native SQLite runtime |
| [`dust_db_postgres`](https://pub.dev/packages/dust_db_postgres) | PostgreSQL runtime |
| [`dust_server`](https://pub.dev/packages/dust_server) | Dart HTTP server runtime |

Start with the [installation guide](https://github.com/dustcodegen/dust#installation)
or add the runtime package your project needs from pub.dev.
